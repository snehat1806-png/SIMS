# Student Information Management System (SIMS)

A Python-based Student Information Management System built using Object-Oriented Programming (OOP) concepts and JSON storage.

This project helps manage student records through a Command Line Interface (CLI).

---

# Features

## Current Features

- Add Student
- List Students
- Search Student
- Auto-generated Student IDs
- JSON-based data storage
- Regex Email Validation
- Duplicate Email Prevention
- Duplicate Phone Number Prevention
- OOP-based Project Structure

---

# Technologies Used

- Python 3
- JSON
- Regular Expressions (Regex)
- Object-Oriented Programming (OOP)
- Git & GitHub
